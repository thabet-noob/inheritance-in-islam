  - PaternalSister               0/1      0%

Shares by Individual:

  - PaternalBrother              0        0%
  - PaternalSister               0        0%

Calculation Steps:

  2. FullBrother blocks PaternalSister from receiving any share. (Rule 13)
  3. Distribute the remaining shares according to relative priority (Rule 14)
